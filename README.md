# Codex Aurora

> 包名 `dsh-codex-aurora`；在 DSH 插件列表里显示为 **Codex Aurora**（取自 `locale/*.json` 的 `meta.title`）。

把 **DeepSeek Harness** 模型菜单里「推理等级」那一行换成一条可拖动的滑条 —— Codex 风格的配色与动效。

> 本包是 `dsh-codex-effort-slider` 的改名 + 动效重做版：配色与动画按 Codex 实机录屏逐帧量取重写。

## 和原版的差别

| | 原版 | 本版 |
|---|---|---|
| 普通档位填充 | 按位置混蓝 → 紫 → 深紫 | **一律纯蓝 `#339CFF`** |
| 紫色 | 从第二档起逐渐出现 | **只有最高档才有** |
| 紫层动画 | 紫色星云 + 横向扫光（2.4s 循环） | **静止底色** + 两层缓慢游走的极光（27s / 41s 来回摆） |
| 星点 | 22 颗从右向左横穿轨道（1.5~8.6s 一圈） | **12 颗匀速左移**（三条星带 30/21/14s），**亮度恒定、不闪烁** |
| 文字色 | 蓝 → 紫罗兰插值 | 非最高档统一蓝，最高档 `#924FF7` |

## 视觉规格（实机量取，非估算）

- 实机量取：轨道 **345×36**、旋钮 **Ø40**（比轨道高 4px，上下各溢出 2px）；
  本插件按同一比例缩到 **轨道 24 / 旋钮 28**（条子更细，旋钮仍是完整圆）
- 填充宽度 = 旋钮圆心 + 半径 − 2px。只画到圆心时，填充右端的圆弧（半径 = 半个轨道高）
  与旋钮不同心，右上/右下角会露出缺口；画到右缘又会在圆心那一行相切、留下 1px 紫边
- 刻度点 Ø3，位于每档位置（最低档不画）
- 最高档底色（跨 8 个时刻逐列取中位）：
  `#7E90FA 0% → #A594FD 35% → #A87FFE 52% → #9458FB 70% → #744AE7 90%`（静止）
- "颜色会轻微变化"来自两层极光：
  `.ces-aurora`（亮，`mix-blend-mode:screen`，27s 斜向来回摆）+ `.ces-shade`（暗，41s 反相摆）
  —— 实机亮区位置随时间在 0%~75% 之间移动，单帧静态渐变复现不了
- 星点：2.2~2.7px 浅紫柔边圆点（核心 `#D19DFF`，实机 2×2 像素、外圈只有 1px 抗锯齿，
  **不是纯白、没有大范围辉光**）；三层星带各 4 颗，`200%` 宽容器匀速左移半层宽，
  左侧出画与右侧复制品入画严格接续 → 看不到闪现

## 安装

已经装进 `~/.dsh/profiles/desktop`：

```jsonc
// profiles/desktop/package.json
"dependencies": { "dsh-codex-aurora": "file:vendor/dsh-codex-aurora" },
"dsh": { "profile": { "bundles": [ ..., "dsh-codex-aurora" ] } }
```

包体放在 `profiles/desktop/vendor/dsh-codex-aurora/`，并同步了一份到 `node_modules/`。
**改完要重启 DSH Desktop 才生效**（客户端 bundle 在启动时打包进 `__DSH_BOOT__`）。

## 用法

1. 打开模型菜单，点「推理等级」那一行 —— 下方多出一条滑条
2. 拖它，或者点滑条上任意位置；滑过中点就切档
3. 键盘：`←` `→` 切一档，`Home` / `End` 到两端
4. 只有拖到**最高档**时，轨道才变成紫罗兰色并亮起星点

## 已知限制

- 依赖官方 DOM 的语义属性（`aria-haspopup` / `aria-controls` / `role="menuitem"`），官方改版会静默失效
- 认不出锚点时**什么都不做**（fail-open），官方菜单保持原样
- 需要重启 DSH 才生效；必须先点开模型菜单才能改档位
